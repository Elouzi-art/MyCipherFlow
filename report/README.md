# CipherFlow — Rapports d'avancement

Ce répertoire conserve les rapports périodiques destinés à l'encadrement pédagogique.

## Organisation

Chaque dossier `Rapport_XX` contient le rapport de la période et ses ressources :
- le PDF final à transmettre à l'enseignant ;
- le fichier LaTeX source (`main.tex`) ;
- le dossier `images/` réservé aux captures et illustrations utilisées dans le rapport.

## Convention de nommage

- PDF : `Rapport_XX.pdf`
- Source LaTeX : `main.tex`
- Images : noms explicites, par exemple `architecture.png`, `guide-page.png`, `tests-build.png`.

Ne pas inclure de captures non vérifiées ni présenter une fonctionnalité planifiée comme déjà réalisée.
